# Welcome to Rmd Studio

This is a plain Markdown document. Rmd Studio opens it in **Markdown mode**:
no YAML front matter, no PDF controls, just a normal `.md` file.

## What stays Markdown

**Bold**, *italic*, ~~strikethrough~~, `inline code` and
[links](https://quarto.org) are written as ordinary Markdown. Headings,
lists, tables and quotes work the same way.

- First bullet
- Second bullet
- Third bullet

1. First step
2. Second step

> Markdown is the source of truth.

| Tool | Purpose |
|:---|:---|
| Markdown | Everyday writing |
| Quarto | Reproducible documents |
| R Markdown | R-based reports |


Use **File → New R Markdown document** or **New Quarto document** when you
need YAML, R code chunks, citations or PDF output.
