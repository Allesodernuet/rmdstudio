Rmd Studio 0.1.0
================

Run "Rmd Studio.exe". The app is self-contained and needs no Python install.

Windows may show SmartScreen because the executable is unsigned. Choose
"More info" -> "Run anyway" if you trust the file.

First use
---------
1. Click Save to choose an .Rmd path.
2. Write in the page. The .Rmd file is rewritten after you pause typing.
3. Open it in RStudio, or use "Open in RStudio" / "Knit to HTML" in the ribbon.

RStudio, R and the Pandoc bundled with RStudio are used when available. The app
does not make network calls or run R code unless you press Knit.

Formatting notes
----------------
Bold, italic, headings, lists, tables, links, code and R chunks become normal
R Markdown. Fonts, colours, highlights and line spacing are stored as Pandoc
HTML styles: they show in HTML output, not in PDF/Word output. Turn this off in
View -> Preserve fonts, colours and spacing for clean Markdown.

Settings are stored in %APPDATA%\Rmd Studio (or a userdata folder beside the exe
if that is not writable).
